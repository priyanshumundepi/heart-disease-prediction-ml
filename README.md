# Heart Disease Prediction using Machine Learning

## Project Overview
This project predicts the presence of heart disease using Machine Learning.

## Dataset
The dataset contains 270 patient records and 14 columns.

## Machine Learning Model
- Logistic Regression

## Dataset Split
- Training Data: 216 samples
- Testing Data: 54 samples

## Model Performance
- Accuracy: 92.59%

## Evaluation
The model was evaluated using:
- Accuracy
- Classification Report
- Confusion Matrix

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Conclusion
The Logistic Regression model achieved an accuracy of 92.59% on the test dataset.

## Disclaimer
This project is created for educational purposes only and is not intended for medical diagnosis.
